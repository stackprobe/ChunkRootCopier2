===============
ChunkRootCopier
===============


----
概要

このインストーラは「CHROCO - CHunk ROot COpier」をインストールします。

ChunkRootCopier は、入力フォルダ配下から選択した一部のファイルを、
同じ相対パス構造で出力フォルダへコピーするための Windows アプリケーションです。

本インストーラでは、GUI アプリケーション GUIChroco と、
実際のコピー処理を行うコマンドラインツール Chroco をまとめて配置します。


----
インストール先

デフォルトのインストール先は以下です。

	%LOCALAPPDATA%\ChunkRootCopier

インストール先は画面上で変更できます。

インストール先フォルダが既に存在する場合、上書き確認が表示されます。
既に ChunkRootCopier がインストールされている場所を指定した場合は、
「再インストール」として実行できます。


----
デスクトップショートカット

インストール時にデスクトップショートカットを作成できます。

同名のショートカットが既に存在する場合、上書き確認が表示されます。


----
インストールに必要なファイル

インストーラと同じ場所に、以下のファイルが必要です。

	GUIChroco.cmp-gz
	GUIChroco.cmp-gz.hash
	Chroco.cmp-gz
	Chroco.cmp-gz.hash

インストール前に各クラスタファイルの SHA-512 ハッシュを検証します。
ファイルが不足している場合、または破損している場合はインストールを中止します。


----
アンインストール

既にインストールされている場所を指定すると、アンインストールを実行できます。

アンインストールでは、指定されたインストール先フォルダ全体を削除します。
インストール先フォルダ内に個人用ファイルなどを置かないでください。

デスクトップショートカットが存在する場合、削除するかどうかを確認します。


----
補足

インストール先フォルダが他のプログラムで使用中の場合、
インストールまたはアンインストールに失敗することがあります。

ChunkRootCopier の使用方法については、インストール後に同梱される
GUIChroco および Chroco の Readme を参照してください。
