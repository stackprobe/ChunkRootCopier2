=========
GUIChroco
=========


----
起動コマンド

GUIChroco.exe


----
補足

・入出力パスと対象パスリストなどの入力情報をコンテキストファイルに保存できます。
　画面右側の「インポート」「エクスポート」ボタンを使用してください。

・起動オプションにコンテキストファイルを指定できます。
　よって GUIChroco.exe やデスクトップ上に作成したショートカットにコンテキストファイルを
　ドラッグ＆ドロップすることによって読み込むことができます。

・画面にコンテキストファイルをドラッグ＆ドロップすることによって読み込むことができます。
